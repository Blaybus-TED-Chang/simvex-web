**발표 자료:**
- [ ] 발표 슬라이드 (5-10장)
  ```
  1. 표지 (프로젝트명, 팀)
  2. 문제 정의
  ```

**데모 시나리오 (3분):**
```
1. 랜딩/인트로 (10초)
   - "SiMVEX, 로봇 암 시뮬레이터입니다"

2. 3D 뷰어 소개 (20초)
   - 카메라 조작 시연
   - 로봇 구조 간략 설명

3. FK 모드 시연 (40초)
   - 각 관절 슬라이더 조작
   - 엔드 이펙터 위치 변화 확인
   - "관절 각도를 직접 조작하는 순기구학입니다"

4. IK 모드 시연 (50초)
   - 모드 전환
   - 목표점 드래그
   - 로봇 자동 이동
   - "목표만 정하면 로봇이 알아서 계산합니다"

5. 경로 프로그래밍 (40초)
   - 3-4개 웨이포인트 저장
   - Play 버튼으로 재생
   - "실제 공장 로봇처럼 프로그래밍 가능합니다"

6. 학습 패널 (20초)
   - 학습 패널 열기
   - FK/IK 설명 간략히 보여주기
   - "이론 학습도 함께 가능합니다"
```

**백업 계획:**
- [ ] 오프라인 녹화 영상 준비

## 예상 Q&A

**Q: 왜 웹으로 만들었나요?**
> 설치 없이 브라우저에서 바로 사용 가능하고,
> 크로스 플랫폼 지원이 용이합니다.

**Q: 실제 로봇과 연동 가능한가요?**
> 현재는 시뮬레이션 전용이지만,
> ROS 연동 등 확장 계획이 있습니다.

**Q: 성능은 어떤가요?**
> WebGL 기반으로 대부분의 현대 브라우저에서
> 60fps 이상 동작합니다.

**Q: 다른 로봇 모델도 지원하나요?**
> 현재는 6축 로봇만 지원하며,
> SCARA, Delta 등 추가 예정입니다.

**Q: 오픈소스인가요?**
> (팀 결정에 따라 답변)
