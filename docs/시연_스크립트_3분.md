# SIMVEX 3분 시연 스크립트

> **서비스**: SIMVEX — 공학 학습용 웹 기반 3D 기계 부품 뷰어
> **시연 시간**: 3분 (180초)
> **시연 순서**: 필수 기능(8개) → 추가 기능(3개)

---

## 도입 (0:00 ~ 0:20) — 20초

> **랜딩 페이지 (`/`)**

- "SIMVEX는 공학 학습용 웹 기반 3D 기계 부품 뷰어입니다."
- 랜딩 페이지 스크롤하며 서비스 소개 간단히 보여주기
- 요금제 섹션 잠깐 노출 후 → **"시작하기"** 클릭

---

## 필수 기능 시연 (0:20 ~ 2:10) — 110초

### 1. 학습 기계/장비 조회 (0:20 ~ 0:35) — 15초

> **모델 목록 페이지 (`/models`)**

- 4개 모델 카드 (드론, 로봇팔, 판스프링, 서스펜션) 확인
- 썸네일 슬라이드쇼 동작 보여주기
- 아래 커뮤니티 모델 섹션도 잠깐 언급
  - "사용자가 직접 업로드한 모델도 열람 가능합니다"
- **드론 모델** 클릭하여 뷰어 진입

---

### 2. 3D 모델 출력 + 인터랙션 (0:35 ~ 1:00) — 25초

> **뷰어 페이지 (`/viewer/drone-combined`)**

- 3D 모델 렌더링 확인 (조명, 머티리얼)
- **마우스 드래그**로 회전 시연
- **스크롤**로 줌 인/아웃
- 36개 부품이 조립도 형태로 배치된 것 확인

---

### 3. 분해/조립 슬라이더 + 제품 정보 (1:00 ~ 1:20) — 20초

> **좌측 사이드바**

- 분해도 슬라이더를 **0% → 100%** 천천히 드래그
- 부품들이 분해 방향으로 퍼지는 것 시연
- 투명도 슬라이더도 살짝 조절
- 우측 **제품 정보 패널**에서 드론 설명 및 이론 펼쳐서 보여주기

---

### 4. 부품 정보 조회 (1:20 ~ 1:35) — 15초

> **3D 뷰포트에서 부품 클릭**

- 부품 **호버** 시 하이라이트 시연
- 부품 **클릭** → 선택 하이라이트 (emissive)
- 우측 **부품 정보 패널**: 부품명, 재질, 역할 설명 확인
- 색상 변경도 간단히 시연

---

### 5. 사용자 데이터 저장 (1:35 ~ 1:45) — 10초

> **새로고침 시연**

- "지금까지의 분해도, 카메라 위치, 노트가 모두 자동 저장됩니다"
- **페이지 새로고침(F5)** → 분해도 값, 카메라 위치, 노트 내용 그대로 유지 확인
- 로그인 시 Supabase 클라우드 동기화 언급

---

### 6. 노트 + AI 어시스턴트 (1:45 ~ 2:10) — 25초

> **우측 사이드 패널**

- **노트 탭** 선택 → 간단한 메모 입력 ("프로펠러 구조 확인")
- **AI 탭** 전환 → "이 드론의 프로펠러는 어떤 원리로 작동하나요?" 질문
- AI 응답 대기 (현재 모델/부품 컨텍스트가 자동 전달됨을 언급)
- 패널 접기/펼치기, 크기 조절 간단히 시연

---

## 추가 기능 시연 (2:10 ~ 2:50) — 40초

### 7. 퀴즈 (2:10 ~ 2:25) — 15초

> **뷰어 내 퀴즈 패널**

- 퀴즈 탭 진입 → 드론 퀴즈 시작
- 객관식 문제 1개 풀어보기 → 정답/오답 피드백
- "부품 클릭" 유형 문제 잠깐 보여주기
- 결과 화면 확인

---

### 8. PDF 출력 (2:25 ~ 2:35) — 10초

> **뷰어 페이지에서**

- PDF 출력 버튼 클릭
- "현재 3D 뷰 스크린샷 + 모델 정보 + 부품 목록 + 노트 내용이 PDF로 생성됩니다"
- 다운로드된 PDF 파일 간단히 보여주기

---

### 9. 워크플로우 차트 (2:35 ~ 2:50) — 15초

> **워크플로우 페이지 (`/workflow`)**

- 새 워크플로우 생성 → 편집기 진입
- 노드 2~3개 빠르게 추가 + 드래그 배치
- 노드 간 **연결선** 클릭으로 생성
- **미니맵** (우하단)으로 전체 레이아웃 확인
- 파일 첨부 + 다운로드 버튼 시연
- "공유 링크를 생성하여 팀원에게 공유할 수 있습니다"

---

## 마무리 (2:50 ~ 3:00) — 10초

- "사용자 모델 업로드도 지원합니다 — GLB/FBX 파일을 드래그하면 자동 분해 설정이 생성됩니다"
- 홈페이지 커뮤니티 모델 섹션 다시 보여주며 마무리
- **"SIMVEX — 3D로 배우는 공학, 감사합니다"**

## 시연 팁

- **AI 응답 대기 시간 대비**: AI 질문은 미리 한 번 보내둔 상태에서 시연하면 안전
- **페이지 전환 최소화**: 뷰어 페이지에서 1~8번까지 연속 시연, 마지막에만 워크플로우로 이동
- **드론 모델 권장**: 36개 부품으로 분해 시연 효과가 가장 뛰어남
- **다크모드**: 시연 전 라이트/다크 중 프로젝터 환경에 맞는 모드로 설정
