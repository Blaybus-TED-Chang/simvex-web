### 5.2 로봇 구조 설명

**설명:** 6축 로봇의 구조와 각 부분 설명

**콘텐츠:**
```markdown
## 6축 다관절 로봇

산업용 로봇 팔의 가장 일반적인 형태입니다.

### 구성 요소

**Base (베이스)**
- 로봇의 고정 기반
- J1 관절: 좌우 회전 (Yaw)

**Shoulder (어깨)**
- J2 관절: 전후 기울임 (Pitch)
- 주요 도달 범위 결정

**Elbow (팔꿈치)**
- J3 관절: 팔 굽힘 (Pitch)
- 수직 도달 범위 확장

**Wrist (손목)**
- J4, J5, J6: 3축 회전
- 엔드 이펙터 방향 제어

### 자유도 (DOF)
6개 관절 = 6 자유도
→ 3D 공간의 모든 위치와 방향 도달 가능
```

**요구사항:**
- [ ] 텍스트 설명
- [ ] 관절 클릭 시 3D 모델 하이라이트 연동
- [ ] 간단한 다이어그램 또는 이미지

### 5.3 순기구학 (FK) 설명

**설명:** FK 개념과 수학적 원리 설명

**콘텐츠:**
```markdown
## 순기구학 (Forward Kinematics)

**정의**
관절 각도 → 엔드 이펙터 위치/방향 계산

**수식**
각 관절의 변환 행렬을 순차적으로 곱합니다:

T_total = T₁ × T₂ × T₃ × T₄ × T₅ × T₆

각 T는 회전(R)과 이동(d)을 포함:
T = | R  d |
    | 0  1 |

**DH 파라미터**
Denavit-Hartenberg 표기법으로 로봇 기구학을 정의합니다.

| i | θ | d | a | α |
|---|---|---|---|---|
| 1 | θ₁| d₁| 0 | 90°|
| 2 | θ₂| 0 | a₂| 0 |
...

**실습**
왼쪽 슬라이더를 조작하여 관절 각도를 변경하고,
엔드 이펙터 위치가 어떻게 계산되는지 확인하세요.
```

**요구사항:**
- [ ] 개념 설명 텍스트
- [ ] 수식 렌더링 (KaTeX 또는 이미지)
- [ ] 실습 안내 문구

### 5.4 역기구학 (IK) 설명

**설명:** IK 개념과 알고리즘 설명

**콘텐츠:**
```markdown
## 역기구학 (Inverse Kinematics)

**정의**
엔드 이펙터 위치/방향 → 관절 각도 계산

**특징**
- FK의 역 문제
- 해가 여러 개 존재할 수 있음
- 해가 없을 수도 있음 (도달 불가 영역)

**CCD 알고리즘**
Cyclic Coordinate Descent

1. 마지막 관절부터 시작
2. 각 관절을 목표 방향으로 회전
3. 베이스까지 반복
4. 수렴할 때까지 사이클 반복

**실습**
IK 모드에서 목표점을 드래그하여
로봇이 자동으로 자세를 계산하는 것을 확인하세요.
```

**요구사항:**
- [ ] 알고리즘 설명
- [ ] 단계별 시각화 (선택)
- [ ] 실습 연동

### 5.5 인터랙티브 튜토리얼

**설명:** 첫 사용자를 위한 단계별 가이드

**요구사항:**
- [ ] 시작 시 튜토리얼 표시 옵션
- [ ] 단계별 하이라이트 + 설명
  ```
  Step 1: "카메라를 움직여보세요"
          → 마우스 드래그 안내

  Step 2: "관절 슬라이더를 조작해보세요"
          → J1 슬라이더 하이라이트

  Step 3: "IK 모드로 전환해보세요"
          → IK 탭 하이라이트

  Step 4: "목표점을 드래그해보세요"
          → 목표 마커 하이라이트

  Step 5: "웨이포인트를 저장해보세요"
          → 저장 버튼 하이라이트
  ```
- [ ] 건너뛰기 / 다시 보지 않기 옵션
- [ ] 언제든 다시 시작 가능

**완료 기준:**
- 5단계 튜토리얼 동작
- 진행 상태 저장 (localStorage)
