# SiMVEX 해커톤 프로젝트 지침

## 프로젝트 개요

**SiMVEX** - 공대생을 위한 엔지니어링 통합 학습 플랫폼

> "노트북 속 나만의 작은 연구실"

### 핵심 가치
- 3D 시뮬레이션을 통한 공학 원리 학습
- 직접 만들어보는 3D CAD 설계
- 노드 기반 워크플로우로 학습 체계화

## 기술 스택 (권장)

### 프론트엔드
```
Next.js 14 (App Router)  - React 기반, Vercel 배포 최적화
TypeScript              - 타입 안정성
Tailwind CSS            - 빠른 스타일링
```

### 3D 그래픽
```
Three.js                - 3D 렌더링 엔진
React Three Fiber (R3F) - React 선언적 Three.js
@react-three/drei       - R3F 유틸리티 컴포넌트
```

### 워크플로우
```
React Flow              - 노드 기반 플로우 차트 라이브러리
```

### 상태 관리
```
Zustand                 - 간단하고 가벼운 상태 관리
```

### 배포
```
Vercel                  - Next.js 최적화 배포 플랫폼
```

## 기능 명세 (MVP 범위)

### 1. 3D 시뮬레이션 학습 (우선순위: 높음)

**MVP 범위:**
- [ ] 3D 뷰어 (회전, 줌, 패닝)
- [ ] 기본 물리 시뮬레이션 1~2개 예제
  - 예: 진자 운동, 기어 시스템, 유체 흐름 시각화
- [ ] 학습 컨텐츠 패널 (설명 텍스트 + 수식)
- [ ] 파라미터 조절 UI (슬라이더 등)

**구현 제외 (해커톤 이후):**
- 복잡한 물리 엔진 통합
- 다양한 산업 기계 시뮬레이션
- 사용자 커스텀 시뮬레이션 생성

### 2. 3D CAD (우선순위: 중간)

**MVP 범위:**
- [ ] 기본 도형 생성 (큐브, 실린더, 구 등)
- [ ] 객체 변형 (이동, 회전, 스케일)
- [ ] 간단한 Boolean 연산 (합집합/차집합) - 시간 허용 시
- [ ] 씬 저장/불러오기 (LocalStorage)

**구현 제외 (해커톤 이후):**
- 정밀한 치수 입력
- 복잡한 스케치 기반 모델링
- 파일 내보내기 (STL, STEP 등)

### 3. 워크플로우 차트 (우선순위: 중간)

**MVP 범위:**
- [ ] 노드 생성/삭제
- [ ] 노드 연결 (드래그 앤 드롭)
- [ ] 노드 타입 (학습 단계, 프로젝트 단계, 메모 등)
- [ ] 차트 저장/불러오기

**구현 제외 (해커톤 이후):**
- 실시간 협업
- 자동 레이아웃 알고리즘
- 외부 서비스 연동

### 4. 공통 기능

**MVP 범위:**
- [ ] 반응형 레이아웃
- [ ] 다크/라이트 테마
- [ ] 랜딩 페이지 (기존 사이트 참고)
- [ ] 기본 네비게이션

**구현 제외:**
- 사용자 인증/로그인
- 백엔드 서버/데이터베이스
- 결제 시스템

## 프로젝트 구조 (권장)

```
simvex/
├── app/
│   ├── page.tsx                 # 랜딩 페이지
│   ├── layout.tsx               # 공통 레이아웃
│   ├── simulation/
│   │   └── page.tsx             # 3D 시뮬레이션 페이지
│   ├── cad/
│   │   └── page.tsx             # 3D CAD 페이지
│   └── workflow/
│       └── page.tsx             # 워크플로우 차트 페이지
├── components/
│   ├── ui/                      # 공통 UI 컴포넌트
│   ├── simulation/              # 시뮬레이션 관련 컴포넌트
│   ├── cad/                     # CAD 관련 컴포넌트
│   └── workflow/                # 워크플로우 관련 컴포넌트
├── lib/
│   ├── store/                   # Zustand 스토어
│   └── utils/                   # 유틸리티 함수
├── public/
│   └── models/                  # 3D 모델 파일
└── styles/
    └── globals.css              # 전역 스타일
```

## 개발 우선순위 전략

### 핵심 원칙
1. **데모 가능한 상태 유지** - 매일 배포 가능한 상태로 유지
2. **핵심 기능 먼저** - 화려함보다 작동하는 기능에 집중
3. **시간 박스** - 각 기능에 시간 제한 설정, 막히면 단순화

### 일일 목표 예시

**Phase 1 (1/29~1/31)**
- Day 1: Next.js 프로젝트 생성, 기본 라우팅, Tailwind 설정
- Day 2: 공통 레이아웃, 네비게이션, 랜딩 페이지 기본 구조
- Day 3: Three.js/R3F 설정, 기본 3D 씬 렌더링

**Phase 2 (2/1~2/4)**
- Day 4-5: 3D 뷰어 컨트롤, 카메라 조작
- Day 6-7: 물리 시뮬레이션 예제 1개 구현 (진자 또는 기어)

**Phase 3 (2/5~2/8)**
- Day 8-9: React Flow 통합, 기본 노드 시스템
- Day 10-11: CAD 기본 도형 생성 및 변형

**Phase 4 (2/9~2/11)**
- Day 12: 기능 통합, 버그 수정
- Day 13: UI 폴리싱, 최종 배포
- Day 14 (2/11): 버퍼 / 발표 준비
